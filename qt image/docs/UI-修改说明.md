# Qt 分层界面说明（2026-11-04）

## 启动

双击 `LibraryGui/run_ui_preview.bat`，运行 `dist/LibraryGui-UI.exe`。启动脚本使用相邻的 `309-4` 数据目录。

新版单独命名，原来的 `dist/LibraryGui.exe` 没有被覆盖。数据操作会作用于所选数据目录，测试程序必须使用临时副本。

## 页面流程

- 首页对应 main.c 的 8 个功能入口：添加、删除、查询、排行、输出、借阅、归还、提醒。
- 添加：点击首页卡片 → 第二页填写校区、书名、类别、价格、总数 → 确认提交。新书使用所填总数；同校区同名书仍按原规则加 1。
- 借阅：点击首页卡片 → 第二页填写图书、读者、数量、日期 → 确认提交。
- 归还：先进入借阅记录列表 → 选中记录 → 点击归还 → 第二页填写数量与日期。
- 删除：先进入图书列表 → 选中图书 → 点击删除并确认。仍使用原来的未归还拦截逻辑。
- 查询、排行、提醒：进入对应列表页，可以返回首页或在列表页间切换。
- 输出：第二页确认目标后输出到数据目录的 output.txt，列出馆藏信息及校区。

## 外观与动态效果

- 深色侧栏、浅色内容区、功能卡片、馆藏统计、统一表格与表单。
- 卡片悬停动画约 150 毫秒，页面淡入约 200 毫秒。
- 右上角“页面动效”可以关闭动画；按钮保留键盘焦点提示。
- 小窗口可滚动；填表时侧栏暂时禁用，使用返回或取消退出填写。
- 首页统计每分钟刷新一次；停留在提醒列表时，每分钟刷新列表，以便跨日期后更新显示。

## 代码位置

- `libraryshell.cpp`：界面外壳、卡片绘制、导航、嵌入式表单、动效和输出页。
- `mainwindow.h`：新增界面成员与方法声明。
- `mainwindow.cpp`：接入界面外壳；三个原弹窗入口改用嵌入式表单执行，原业务处理继续使用。
- `tests/ui_smoke.cpp`：离屏导航截图、返回/取消及表单提交检查。
